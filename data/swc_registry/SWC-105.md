# SWC-105: Unprotected Ether Withdrawal

## Vulnerability Description
A function that transfers ETH (or tokens) out of the contract is missing an access control check. As a result, any address can trigger the function and drain the contract's balance to an arbitrary address.

## Severity
High

## Detection Rules & Indicators
- A `public` or `external` function containing `.transfer()`, `.send()`, or `.call{value: ...}` that allows the recipient to be specified by the caller, without checking `msg.sender == owner` or equivalent.
- Lack of `onlyOwner` or similar role-based modifiers on functions that move funds.

## Vulnerable Example
```solidity
contract VulnerableVault {
    // Anyone can call this function and drain the contract
    function withdrawAll(address payable recipient) public {
        recipient.transfer(address(this).balance);
    }
}
```

## Safe Example / Remediation
```solidity
contract SafeVault {
    address public owner;
    
    modifier onlyOwner() {
        require(msg.sender == owner, "Not owner");
        _;
    }

    // Only the owner can withdraw
    function withdrawAll(address payable recipient) public onlyOwner {
        recipient.transfer(address(this).balance);
    }
}
```

## False-Positive Conditions & Counterexamples
- **Internal Accounting Checked**: If the withdrawal function checks that the caller is only withdrawing their *own* balance (e.g., `require(balances[msg.sender] >= amount)`), this is **safe** and intended. It is not an unprotected withdrawal just because `onlyOwner` is missing.
- **Custom Access Control**: The contract might use custom access control logic (e.g., checking a mapping `require(isAuthorized[msg.sender])`). Tools that only look for `onlyOwner` might flag this incorrectly.
- **Flash Loans**: Functions providing flash loans send out large amounts of funds to arbitrary addresses, but verify that the funds (plus a fee) are returned by the end of the transaction. This is **safe** if the return check is implemented correctly.

## Solidity-Version Notes
Applies to all versions.
