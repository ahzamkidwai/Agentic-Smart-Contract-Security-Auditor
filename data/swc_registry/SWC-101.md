# SWC-101: Integer Overflow and Underflow

## Vulnerability Description
An arithmetic operation on a fixed-size integer type produces a result that falls outside the representable range. This causes the value to silently wrap around. For instance, `uint8` 255 + 1 becomes 0, and `uint256` 0 - 1 becomes a massive number (2^256 - 1).

## Severity
High

## Detection Rules & Indicators
- Manual arithmetic (`+`, `-`, `*`) on `uint`/`int` types without bounds checks or `SafeMath`.
- Contracts targeting Solidity versions before `0.8.0`.

## Vulnerable Example
```solidity
pragma solidity ^0.7.0;

contract Token {
    mapping(address => uint) public balances;
    
    function transfer(address to, uint amount) public {
        require(balances[msg.sender] - amount >= 0); // Always true for uint! Underflows instead.
        balances[msg.sender] -= amount; // Underflows if amount > balance
        balances[to] += amount; // Overflows
    }
}
```

## Safe Example / Remediation
```solidity
pragma solidity ^0.8.0;

contract Token {
    mapping(address => uint) public balances;
    
    // In Solidity >= 0.8.0, underflow/overflow will automatically revert.
    function transfer(address to, uint amount) public {
        balances[msg.sender] -= amount; 
        balances[to] += amount;
    }
}
```

## False-Positive Conditions & Counterexamples
- **Solidity ^0.8.0**: Any arithmetic operation in Solidity 0.8.0 or higher is safe by default as the compiler inserts panic checks (unless inside an `unchecked` block). A detector flagging standard `+` or `-` as SWC-101 on a `pragma solidity ^0.8.0;` contract is a false positive.
- **SafeMath Usage**: If a contract uses OpenZeppelin's `SafeMath` (e.g., `a.add(b)`), it is protected.
- **`unchecked` blocks used safely**: Sometimes `unchecked` blocks are used for gas optimization when the logic guarantees no overflow (e.g., in a `for` loop `unchecked { ++i; }`). This is safe and not a vulnerability.

## Solidity-Version Notes
- `< 0.8.0`: Requires manual bounds checking or `SafeMath`.
- `>= 0.8.0`: Reverts on overflow/underflow automatically. Use `unchecked { ... }` to explicitly allow wrapping (for gas savings).

## Related Detectors
- Slither: `math` (deprecated/adjusted for 0.8.x)
