# MOD-004: Oracle Manipulation (Spot Price)

## Vulnerability Description
A smart contract relies on the instantaneous "spot price" of an asset from an Automated Market Maker (AMM) like Uniswap V2, or relies on a thin, easily manipulated liquidity pool to determine the value of collateral, rewards, or debt. An attacker can use a flash loan to massively imbalance the pool, altering the spot price, interact with the vulnerable contract at the manipulated price, and then reverse the imbalance.

## Severity
High

## Detection Rules & Indicators
- Using AMM reserves directly to calculate price: `price = reserveA / reserveB`.
- Using `balanceOf(address(this))` to determine share value when the balance can be easily inflated by a flash loan.
- Lack of Time-Weighted Average Price (TWAP) or decentralized oracle (Chainlink) usage.

## Vulnerable Example
```solidity
contract VulnerableLending {
    IUniswapV2Pair public pair;

    // Vulnerable: Relies on instantaneous spot price
    function getCollateralValue(uint amount) public view returns (uint) {
        (uint112 reserve0, uint112 reserve1, ) = pair.getReserves();
        uint spotPrice = reserve1 / reserve0; 
        return amount * spotPrice;
    }

    function borrow(uint amountToBorrow) public {
        uint collateralValue = getCollateralValue(collateralBalance[msg.sender]);
        require(collateralValue >= amountToBorrow, "Undercollateralized");
        // ... 
    }
}
```
*Attack: Flash loan massive amounts of Token0. Swap for Token1 on the Pair. `reserve1 / reserve0` skyrockets. The attacker deposits a tiny amount of collateral, borrows the entire vault's liquidity, and repays the flash loan.*

## Safe Example / Remediation
```solidity
import "@chainlink/contracts/src/v0.8/interfaces/AggregatorV3Interface.sol";

contract SafeLending {
    AggregatorV3Interface public priceFeed;

    // Safe: Uses Chainlink decentralized oracle network
    function getCollateralValue(uint amount) public view returns (uint) {
        (
            uint80 roundID, 
            int price,
            uint startedAt,
            uint timeStamp,
            uint80 answeredInRound
        ) = priceFeed.latestRoundData();
        
        require(price > 0, "Invalid price");
        require(timeStamp >= block.timestamp - 1 hours, "Stale price");
        
        return amount * uint(price);
    }
}
```

## False-Positive Conditions & Counterexamples
- **TWAP Usage**: If the contract uses Uniswap V2/V3 TWAP (Time-Weighted Average Price) over a sufficient duration (e.g., 30 minutes), it is **safe** against flash loans because flash loans exist only within a single block and cannot alter historical averages.
- **Chainlink Feeds**: If the contract reads from `AggregatorV3Interface.latestRoundData()`, it is **safe** from single-block manipulation (assuming the feed is healthy).
- **Internal Accounting**: If `balanceOf` is used, but it's checking the balance of a non-flash-loanable, tightly controlled internal token, it might not be exploitable.

## Solidity-Version Notes
Applies to all versions.
